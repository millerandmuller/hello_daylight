Run it yourself

Hello Daylight is open source. Everything specific to one operator is configuration: no keys, no allowlist and no project ids live in the repository.

  1. Create a Google Cloud project and a Firebase project on it; switch on Firestore (Native) and Google sign-in.
  2. Put your Gemini key and a session secret into Secret Manager.
  3. Run deploy/deploy.sh from the repository. It builds one image and sets up the web service, the nightly job and the scheduler.
  4. Add your first account to DAYLIGHT_ADMIN_EMAILS, sign in, and add the others on the admin page.

The full steps, with costs and caps, are in the README.
